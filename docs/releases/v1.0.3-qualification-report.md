## 3. Proof Class Taxonomy (P0 through P4)

To replace ambiguous claims with precise engineering semantics, NEURONIX OS classifies all features under five rigorous proof classes:

- **P0 (Mathematical Determinism):** Pinned nixpkgs hashes, bit-identical two-build evaluation, cryptographic SHA-256 asset checksums.
- **P1 (Automated CI Verification):** Automated multi-architecture flake evaluation, dual-mode E2E micro-VM boot verification, and 1,028 automated harness assertions.
- **P2 (Qualified Reference Hardware):** Empirical validation across 8 reference platforms (Lenovo ThinkPad T14, Framework 13, AMD/Intel Workstations, Dell XPS PRIME, Zephyrus G14, Apple Silicon).
- **P3 (Declarative Module Support):** Composable NixOS modules declaring subsystem policies across the 27 hardware pillars.
- **P4 (Experimental / Community Validated):** Optional extensions such as Wayland fractional scaling, custom desktop compositor rules, and bleeding-edge user packages.
